
**Linked-Tec** es una aplicación de red social diseñada para el Tecnológico de Zacatecas. La plataforma permite a los usuarios conectar con otros miembros de la comunidad, enviar mensajes y buscar oportunidades de empleo.

## Descripción

Este proyecto es una red social que ofrece funcionalidades para:

- **Mensajería:** Permite a los usuarios enviar y recibir mensajes directos.
- **Empleos:** Ofrece una sección para la publicación y búsqueda de empleos.
- **Conexiones:** Facilita la conexión entre estudiantes y profesionales del Tecnológico de Zacatecas.
- **Comunidad:** Fomenta la interacción y el networking dentro de la comunidad educativa.

## Instalación

Para configurar y ejecutar el proyecto localmente, sigue estos pasos:

1. **Clona el repositorio:**

   \`\`\`bash
   git clone https://github.com/Linked-Tec/Linked-back.git
   \`\`\`

2. **Accede al directorio del proyecto:**

   \`\`\`bash
   cd Linked-back
   \`\`\`

3. **Instala las dependencias:**

   \`\`\`bash
   npm install
   \`\`\`

4. **Configura las variables de entorno:**

   Crea un archivo `.env` en la raíz del proyecto y añade las variables necesarias (por ejemplo, configuraciones de base de datos).

5. **Inicia el servidor:**

   \`\`\`bash
   npm start
   \`\`\`

   Para desarrollo, puedes usar Nodemon que reinicia el servidor automáticamente cuando hay cambios:

   \`\`\`bash
   npm run start:dev
   \`\`\`

## Scripts

- **start:** Inicia la aplicación con Node.js.
- **start:dev:** Inicia la aplicación en modo desarrollo con Nodemon.
